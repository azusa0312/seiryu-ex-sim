# 極青龍征魂戰 練習場（FF14 4.5）

3D 機制練習場：你只控制自己，其他 7 人是照攻略走位的 NPC；站錯會立刻停下並用中文說明原因。
每個機制可以單選，也能跑全程。

**線上版**：https://azusa0312.github.io/seiryu-ex-sim/

**操作**：WASD 移動、空白鍵跳躍、拖曳轉視角、滾輪縮放、Enter 開始／重來。

攻略依據：B 站菓子君〈【菓子】FF14极青龙征魂战 超详解攻略〉（BV1w4411W72m）的示意圖與最後的流程總結，
時間軸參考 cactbot 的 seiryu-ex 時間軸與 Console Games Wiki。

## 機制（全程順序）

| 段落 | 內容 |
| --- | --- |
| 陰陽五行＋九字切＋紅圈 | 全屏後格子狀直線，4 人（DPS 或坦補）紅圈：全員一人一格散開 |
| 固定鋼鐵 | 太極之印：離王 8m 以上 |
| 咒怨的替身 | 拉怪的坦克被詛咒，另一位坦克到王正面（北）吃無情之魂，其他人遠離 |
| 車輪怪 | 藍車輪（北）連治療 → 治療去南邊 C 點，其他人進藍色直線分攤；紅車輪（東西）連 DPS → 紅線朝場外 |
| 石頭怪 | 百噸揮打（東西大圓，站中間）→ 四風橫線（站王旁的空隙）→ 金棒截線（MT 西北、ST 東北把扇形朝北） |
| 轉場＋蛇潮 | 場地變水上岩島；蛇從某一邊衝過來推 22m → 站到蛇那側靠邊 |
| 大太法師 | 三次手印（舉哪隻手拍哪半場）→ 自然之力（中心擊退 10m）＋蛇潮：離開中央、往蛇那側站約 5m |
| 直線分攤＋荒魂燃燒 | 全員在王南側吃兩次直線分攤（H1 → H2） |
| 鋼鐵月環→九字切→鋼鐵月環 | 陰陽之印兩下（順序隨機）；九字切兩波：第一波打完立刻踩到剛打過的線上 |
| 升龍踩塔＋AC 分攤 | 先全員集合放水圈 → 紅圈 4 人去正點散開、另外 4 人踩斜角塔 → A 組北／C 組南分攤 |
| 死刑 ×2 | 全屏 → 換 T 兩次 → 全屏 |
| 石頭怪＋鋼鐵月環 | 揮打與鋼鐵月環同時（站中間直線上，再依順序進出）→ 截線 → 車輪怪 → 紅圈散開 |
| 中段 | 九字切 → 大太法師蛇潮 → 鋼鐵月環 → 大太法師蛇潮 → AC 分攤 |
| 最後 | 鋼鐵月環 → 升龍踩塔 → 九字切 → 全屏 ×3 → 狂暴 |

## 站位

- 場標：A 北、B 東、C 南、D 西（影片示意圖，都在場邊）。
- 升龍踩塔搭檔：MT/D1（北、西北塔）、ST/D2（東、東北塔）、H1/D3（西、西南塔）、H2/D4（南、東南塔）。
  有紅圈的人去正點，沒紅圈的搭檔去同一區的斜角塔。
- AC 分攤：A 組 MT・ST・H1・D4 往北（跟 H1），C 組 D1・D2・D3・H2 往南（跟 H2）。

## 自行推斷、請確認

- 範圍大小（鋼鐵 8m、月環安全 5m、紅圈 5m、塔 3.5m、九字切線寬等）與讀條時間都是推估值。
- 九字切：第一波縱 4 橫 5 條，第二波剛好打第一波的安全格（依 Wiki「第二波覆蓋第一波安全處」）。
- 蛇潮推 22m、自然之力推 10m 是為了讓「站蛇那側」「不要太外面」兩個規則成立而設定的數值。
- 咒怨的替身用「誰離王正面最近」判定誰吃死刑（實際遊戲是仇恨）。
- AC 分攤影片只畫出 7 人，D4 歸在 A 組是推斷。
- 略過：小怪階段的泥巴怪（打斷石膚、分批擊殺）、第二階段水裡的白浪。
